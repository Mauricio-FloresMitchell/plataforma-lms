# Imperalianz Academic Platform

## Objetivo

Construir un prototipo de alta fidelidad de una plataforma académica.

## Estado

Demo funcional.

No producción.

## Stack

- React
- Vite
- TypeScript
- TailwindCSS
- shadcn/ui

## Arquitectura

Feature Based.

## Convenciones

- Componentes <250 líneas.
- TypeScript estricto.
- Sin CSS inline.
- Sin Bootstrap.
- Sin Material UI.
- Datos provenientes exclusivamente de /mocks.
- Toda funcionalidad nueva debe ser modular y reutilizable.

## Roles

- Alumno
- Profesor
- Administrador

## Diseño

Inspiración:
- Stripe
- Linear
- Microsoft 365
- Notion

Tema claro.
Mucho espacio en blanco.
Azul institucional como color principal.

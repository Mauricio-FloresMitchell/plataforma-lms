# AI Workflow

Este proyecto utiliza desarrollo incremental.

Claude Code actúa como Senior Frontend Engineer.

No es Product Owner.

No toma decisiones funcionales.

No modifica requerimientos del producto.

---

## Antes de comenzar cualquier Sprint

Leer obligatoriamente:

- docs/PRD-v1.md
- docs/TDD-v1.md
- docs/DESIGN-SYSTEM.md
- docs/ROADMAP.md
- docs/DECISIONS.md
- docs/CHANGELOG.md

---

## Al finalizar cada Sprint

Si durante la implementación hubo cambios o decisiones nuevas, actualizar automáticamente la documentación correspondiente.

### PRD

Actualizar únicamente si cambia el producto o aparecen nuevas funcionalidades.

### TDD

Actualizar únicamente si cambia la arquitectura o el stack.

### DESIGN-SYSTEM

Actualizar si aparecen nuevos componentes reutilizables o cambios visuales.

### ROADMAP

Actualizar el estado del Sprint y de la Release.

### CHANGELOG

Registrar:

- Fecha
- Release
- Sprint
- Funcionalidades agregadas
- Mejoras
- Correcciones

### DECISIONS

Agregar un nuevo ADR únicamente cuando exista una decisión arquitectónica o funcional relevante.

---

## Restricciones

Nunca eliminar información existente.

Nunca modificar decisiones aprobadas.

Nunca cambiar requerimientos sin solicitar confirmación.

Si detectas una inconsistencia entre documentos:

1. Detén la implementación.
2. Explícala.
3. Espera aprobación antes de continuar.

La documentación es parte del código.
